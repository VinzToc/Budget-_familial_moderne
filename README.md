# Budget-_familial_moderne
Une application complète pour le suivi du budget de la famille. L'app permet d'uploader un fichier csv issu de votre banque et permet de gérer le suivi de vos charges ainsi que d'établir un budget mensuel à respecter, basé sur les dépenses des mois précédents..

Le stockage des données est local dans votre navigateur (local storage), vous pouvez utiliser l'application via le lien page sans risques. Les exports et imports peuvent être placés ou vous le souhaitez sur votre appareil.
